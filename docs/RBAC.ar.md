# إدارة الأدوار والصلاحيات (RBAC)

دليل المدير لإعداد أدوار المستخدمين في Sanity Cloud بحيث يحصل كل موظف على الصلاحيات المناسبة لدوره فقط.

---

## مكان الإعداد

كل إدارة الأدوار تتم **خارج الكود**، من خلال:

> [sanity.io/manage](https://sanity.io/manage) → اختر مشروع **MediCare Plus** → تبويب **Members** و **Roles & Permissions**.

تحتاج صلاحية **Administrator** على المشروع لإجراء هذه التغييرات.

---

## الأدوار المعتمدة (4 أدوار)

| الدور | الوصف | الصلاحيات |
|---|---|---|
| **Administrator** | المسؤول الفنّي / المدير العام | وصول كامل لكل المحتوى + إدارة المستخدمين والأدوار |
| **Content Editor** | محرّر المحتوى / فريق التسويق | قراءة وكتابة فقط على المقالات، التعليقات، العروض |
| **Bookings Manager** | مسؤول الحجوزات / منسّق العيادات | قراءة وكتابة على الأطبّاء، الأقسام، الخدمات. قراءة فقط على الباقي |
| **Viewer** | للعرض / موظفو الاستقبال | قراءة فقط على كل المحتوى. لا توجد صلاحيات كتابة |

---

## خطوات الإعداد التفصيلية

### 1) إنشاء الأدوار المخصّصة

في **Members → Roles** اختر **+ Add custom role** وأنشئ الأدوار التالية:

#### Content Editor
- **Read access**: ✓ All document types
- **Write access (create / update / delete)**:
  - ✓ `article`
  - ✓ `testimonial`
  - ✓ `offer`
  - ✗ `department`, `doctor`, `service`, `insurance`
  - ✗ singletons (`siteSettings`, `homePage`, `topBar`, `footer`)
- **Publish**: ✓ for the writable types only

#### Bookings Manager
- **Read access**: ✓ All
- **Write access**:
  - ✓ `department`
  - ✓ `doctor`
  - ✓ `service`
  - ✗ everything else
- **Publish**: ✓ for the writable types

#### Viewer
- **Read access**: ✓ All
- **Write access**: ✗ none
- **Publish**: ✗ no

### 2) دعوة الأعضاء

في **Members → Invite member**:
1. اكتب البريد الإلكتروني للموظف.
2. اختر الدور المناسب من القائمة المنسدلة.
3. اضغط **Send invitation**.

سيستلم الموظف بريداً به رابط للانضمام. عند فتحه يتم تسجيل الدخول بـ Google أو إنشاء حساب Sanity جديد.

### 3) سياسة الموافقة المسبقة

- **Administrator**: واحد أو اثنان فقط (مدير الموقع + المدير الفنّي).
- **Content Editor**: 2-3 موظفين (فريق التسويق / محرّر المحتوى).
- **Bookings Manager**: 1-2 (منسّق العيادات).
- **Viewer**: حسب الحاجة (موظفو الاستقبال، المتدرّبون).

## مراجعة دورية

كل **3 أشهر** يجب على المدير:

1. مراجعة قائمة الأعضاء في `sanity.io/manage → Members`.
2. إزالة من لم يعد في الفريق.
3. تخفيض صلاحيات من تغيّر دوره الوظيفي.
4. تفعيل **2-Factor Authentication** لكل من له دور Editor أو أعلى.

---

## استكشاف الأخطاء

**المستخدم يقول "لا أستطيع تعديل ___":**  
تحقق من دوره في `sanity.io/manage`، وقارن بالمصفوفة أعلاه. إن لزم، رقّ صلاحياته.

**أريد منح صلاحية مؤقّتة لمستشار خارجي:**  
1. أنشئ دوراً مخصّصاً بصلاحيات محدودة.
2. ادعُه بهذا الدور.
3. أعدّ تذكيراً للإزالة بعد انتهاء المهمّة.

**خسرت كلمة المرور:**  
استخدم رابط "Forgot password" في صفحة تسجيل الدخول. كل الحسابات مرتبطة بإيميل.
